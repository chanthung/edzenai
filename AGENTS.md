# Project rules

- Teacher Employee IDs are generated by a database trigger (school-scoped EMP-NNNN, advisory-locked) and locked once set; the UI never edits them — keeps IDs stable and collision-free.
- Teacher HR employment_status is separate from is_active (login access) — changing HR status must never block sign-in.
- Teacher HR import uses shared pure validation/outcome helpers and a user-JWT Edge Function verifying exact school_admins membership; writes only allowlisted HR fields on existing teachers and returns per-row outcomes, preserving names, account links, IDs and assignments.
- Global Admin access badges use the authoritative effective-state RPC; explicit paid renewals align lifecycle anchors and clear termination, while invoice-only edits never alter access expiry.
